    Explanation:
No mismatch. const prevents reassignment of the variable itself; it does not make the array immutable.
7. const a={x:{y:1}}; const b={...a}; b.x.y=99; console.log(a.x.y);
    Prediction:99
    Explanation:
No mismatch. The spread operator creates a shallow copy, so a.x and b.x refer to the same nested object.

9. const o={n:'x', reg(){return this.n}, arrow:()=>this?.n};
console.log(o.reg(), o.arrow());
    Prediction:x undefined
    Explanation:No mismatch in a normal browser script. reg() gets this from the object call (o.reg()), but the arrow function does not create its own this; it captures the surrounding this.
10. console.log([1,2,3].map(n=>n*2), [1,2,3].forEach(n=>n*2));
    Prediction:[2, 4, 6] undefined
    Explanation:No mismatch. map() creates and returns a new array, whereas forEach() executes the callback for each element but returns undefined.
